# アクセス制御要件

「誰が何をできなければならないか」「誰が何をできてはいけないか」を、Keycloak・スコープ・トークンといった実装手段に一切触れない**業務要件**として定義する。[access-control-design.md](access-control-design.md)の各表は、ここで定めた要件番号（BR1, BR2, ...）に対応付けて検証できるようにする。

## 登場する主体

| 主体 | 説明 |
|---|---|
| junior アナリスト | 不正検知業務の担当者。担当地域が割り当てられている |
| senior アナリスト | 同上。juniorより広い範囲を扱える権限を持つ |
| AIエージェント | アナリストの依頼を受けて取引パターンを分析し、凍結を提案する。人間の代理として動くが、それ自体は人間ではない |
| 決済処理 | 入出金・振込を実行する業務処理。特定のアナリストの代理ではなく、システムそのものとして動く |

## 対象となるデータ・操作

| データ・操作 | 説明 |
|---|---|
| 口座の取引情報 | 各口座は地域（`region`）とティア（`standard`／`high-value`）を持つ |
| 凍結の提案 | 口座を凍結すべきという提案を記録する操作。それ自体は口座に何の効果も及ぼさない（可逆・低リスク） |
| 凍結の実行 | 口座を実際に凍結する操作（不可逆・高リスク） |
| 入出金・振込 | 通常の決済業務 |

## 業務要件

**BR1（担当地域の原則）**：アナリストは、自分が担当する地域の口座の取引情報のみを閲覧できる。担当地域外の口座の取引情報は一切閲覧できてはならない。

**BR2（juniorの制限）**：junior権限のアナリストは、担当地域内であってもhigh-value口座の取引情報を閲覧できてはならず、凍結もできてはならない。

**BR3（seniorの権限）**：senior権限のアナリストは、担当地域内であればstandard・high-value問わず取引情報を閲覧でき、凍結もできる。

**BR4（AIエージェントの閲覧範囲の上限）**：AIエージェントがあるアナリストの依頼を受けて取得できる取引情報の範囲は、そのアナリスト本人がBR1〜BR3に基づいて閲覧できる範囲を**超えてはならない**。AIエージェントを経由することで、本人が見られない情報が見られるようになってはならない。

**BR5（AIエージェントは実行できない）**：AIエージェントは凍結を提案（記録）できるが、口座凍結を実行する手段を一切持ってはならない。これはアナリストの権限レベルや担当地域に関わらず、常に成り立たなければならない。

**BR6（人間の確定操作の必須化）**：口座凍結の実行は、その口座に対して権限を持つアナリスト本人が、明示的な確定操作（UI上のボタン操作等、AIエージェントの応答とは別の行為）を行った場合に限り実行されてよい。AIエージェントの提案が自動的に実行に繋がってはならない。

**BR7（決済処理の独立性）**：入出金・振込処理は、不正検知・凍結に関するアナリストの権限体系（担当地域・権限レベル）の影響を受けずに実行されてよい。この処理はアナリストの代理として動くものではなく、アナリストの持つ制約（BR1〜BR3）を適用する対象ではない。

**BR8（事後追跡可能性）**：口座凍結が実行された場合、その実行が事前のAIエージェントの提案に基づくものであれば、どの提案に基づく実行かを事後に特定できなければならない。また、誰（どのアナリスト）が実行したかを事後に特定できなければならない。

## 誰が何をできる／できないか（早見表）

| 操作 | できる主体 | できない主体 |
|---|---|---|
| 担当地域内のstandard口座の取引照会 | junior/senior アナリスト本人。当該アナリストの依頼を受けたAIエージェント（BR4） | 担当地域が異なるアナリスト |
| 担当地域内のhigh-value口座の取引照会 | senior アナリスト本人。当該seniorの依頼を受けたAIエージェント（BR4） | junior アナリスト（BR2）。担当地域が異なるアナリスト（BR1） |
| 凍結の提案（記録のみ） | AIエージェント（アナリストの依頼のもとで） | — （提案自体は低リスクなため主体を制限する要件はない） |
| 凍結の実行 | 権限のあるアナリスト本人による明示的な確定操作のみ（BR6） | AIエージェント（いかなる場合も。BR5） |
| 入出金・振込 | 決済処理（BR7） | アナリスト・AIエージェント（この操作の主体ではない） |
